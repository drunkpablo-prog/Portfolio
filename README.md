# Private Screening

*A Cinephile's Magazine*

## Project Overview

**Private Screening** is a personal film magazine exploring selected works from American and European cinema.

The project combines film research, critical writing, editorial direction, and visual design.

## My Role

* Editorial direction
* Film selection
* Film research and analysis
* Writing and editing
* Magazine design and layout
* Proofreading

## Contents

The magazine features selected films from American and European cinema, with a focus on directors, characters, themes, visual style, and personal interpretation.
